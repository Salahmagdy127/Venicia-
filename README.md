# فينيسيا · Venicia Resort Suite

نظام تشغيل متكامل لقرية فينيسيا على البحيرة — حجوزات، نقاط بيع، حساب النزيل،
هاوس كيبينج، وتقارير المالك. عربي وإنجليزي، RTL كامل، وضع فاتح وداكن.

## التشغيل

**دبل كليك على أيقونة «فينيسيا» اللي على سطح المكتب.**

بيفتح في شباك لوحده بلا تبويبات ولا شريط عنوان — شكل برنامج مش موقع.
مفيش أي شباك أسود بيظهر، ولما تقفل الشباك السيرفرات بتتقفل لوحدها.

| | |
|---|---|
| الشورت كت | `wscript.exe launch.vbs` — بيشغّل [launch.ps1](launch.ps1) مخفي |
| النظام | <http://127.0.0.1:8000> |
| توثيق الـ API | <http://127.0.0.1:8000/docs> |
| السجلات | `%LOCALAPPDATA%\Venicia\logs` |

**سيرفر واحد بس.** FastAPI بيقدّم الـ API والواجهة المبنية مع بعض — مفيش
node شغال وقت العرض، ومفيش بروكسي. المشغّل بيبني الواجهة لوحده لو الكود
اتغيّر بعد آخر بناء.

```powershell
.\launch.ps1 -Visible    # نفس الحاجة بس بتشوف الرسايل
.\launch.ps1 -Rebuild    # يعيد بناء الواجهة بالعافية
```

للتطوير (تعديل الواجهة والتحديث اللحظي):

```powershell
cd frontend; npm run dev     # على 5173، بيوجّه /api للباك إند
```

عايز الشورت كت على جهاز تاني؟ اعمله يدوي: الهدف `wscript.exe`،
والمُعامل مسار `launch.vbs`، والأيقونة `venicia.ico`.

**الدخول:** `owner` / `venicia2026`


### قاعدة البيانات

`DATABASE_URL` في `backend/app/core/config.py` هي المفتاح الوحيد:
SQLite للعرض، PostgreSQL وقت التنفيذ — من غير أي تغيير في الكود.
الأنواع كلها محايدة (`BigInteger.with_variant`, `Numeric`, `JSON`).

**قرارات السعة:**

- **جدول عدّاد للإتاحة** (`availability_calendar`) — الإتاحة بتتقري من صف واحد
  مش من مسح الحجوزات، والحجز بيتم بـ `UPDATE` شرطي ذرّي يمنع الـ overbooking.
- **ترقيم بالمؤشّر** (keyset) بدل `OFFSET` — عمق الصفحة مبيأثرش على السرعة.
- **جداول ملخّص يومية** — الداشبورد بيقرا منها، فسرعته ثابتة مهما كبرت الحركة.
- **أسماء وأسعار مخزّنة داخل سطر الفاتورة** — الفاتورة القديمة متتغيّرش لو السعر اتعدّل.
- **`audit_log` إضافي بس** — الإلغاء بيتم بقيد عكسي، مفيش مسح ولا تعديل.

## القواعد المصرية المطبّقة

- الخدمة **12%** قبل الضريبة، والضريبة **14%** على (المبلغ + الخدمة).
- الويك إند **الجمعة والسبت**.
- الفاتورة الإلكترونية: الحقول والبنية جاهزة في `EInvoice` — الربط بمصلحة الضرائب لسه.
- عمولات القنوات محسوبة ومخزّنة لكل حجز (بوكينج 15–18%).
